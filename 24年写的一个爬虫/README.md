# 天气预报爬虫

#### 何意味(记录于2025.11.10)
当时的课设，那时还在工程力学专业，写这个爬虫用了三四天吧，虽然写的有点史但是过程还是很开心的。做这个课设的过程很大程度上让我下定决心转离工程力学专业。<br>
功能就是爬取气象网青岛近七日的天气，然后提取天气信息制表，然后交给ai原神DeepSeek帮我分析天气，最后再制作几张草率的图表。<br>
半年过去了，那些库的用法我忘得一干二净，这咋办，过两天还要打数学建模比赛。还是叫AI帮忙吧<br>

#### 食用方法（真的会有人用？）
打开code_1.py文件，run，然后等着就行了。<br>
