# 7-1 公路村村通

#### 题目描述
现有村落间道路的统计数据表中，列出了有可能建设成标准公路的若干条道路的成本，求使每个村落都有公路连通所需要的最低成本。

### 输入格式
输入数据包括城镇数目正整数 n（≤1000）和候选道路数目 m（≤3n）；随后的 m 行对应 m 条道路，每行给出 3 个正整数，分别是该条道路直接连通的两个城镇的编号以及该道路改建的预算成本。为简单起见，城镇从 1 到 n 编号。

### 输出格式:
输出村村通需要的最低成本。如果输入数据不足以保证畅通，则输出 −1，表示需要建设更多公路。

### 输入样例
```
6 15
1 2 5
1 3 3
1 4 7
1 5 4
1 6 2
2 3 4
2 4 6
2 5 2
2 6 6
3 4 6
3 5 1
3 6 1
4 5 10
4 6 8
5 6 3
```

### 输出样例
```
12
```

 ### 题解
 ```c
#include<iostream>
#include<vector>
using namespace std;
const int INF = 1E9;
int Prim(int Nv, vector<vector<int>> vValue){
    vector<int> vLowCost(Nv+1, INF);
    vector<bool> inTree(Nv+1 ,false);
    int totalcost = 0;
    int edgeCount = 0;

    inTree[1] = true;
    for(int v = 2; v <= Nv; ++v){
        vLowCost[v] = vValue[1][v];
    }

    for(int i = 2; i <= Nv; ++i){
        int minCost = INF;
        int u = -1;

        for(int v = 1; v <= Nv; ++v){
            if(!inTree[v] && vLowCost[v] < minCost){
                minCost = vLowCost[v];
                u = v;
            }
        }

        if(u == -1){
            return -1;
        }

        inTree[u] = true;
        totalcost += minCost;
        edgeCount++;

        for(int v = 1; v <= Nv; ++v){
            if(!inTree[v] && vValue[u][v] < vLowCost[v]){
                vLowCost[v] = vValue[u][v];
            }
        }
    }

    return (edgeCount == Nv - 1)? totalcost: -1;
}
int main(){
    int Nv, Ne;
    cin>>Nv>>Ne;
    vector<vector<int>> vValue(Nv+1, vector<int>(Nv+1, INF));
    for(int i = 0; i < Ne; i++){
        int S,E,cost;
        cin>>S>>E>>cost;
        vValue[S][E] = cost;
        vValue[E][S] = cost;
    }
    cout<<Prim(Nv, vValue);
    return 0;
}
```
